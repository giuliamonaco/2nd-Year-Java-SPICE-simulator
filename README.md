# Analog Circuit Simulator

## Overview

This project is a Java-based analog circuit simulator developed for a COE318 lab. The program allows users to create a simple circuit by entering **resistors** and **DC voltage sources** through the command line. The circuit elements are stored and can be displayed in **SPICE netlist format**.

The project demonstrates object-oriented programming concepts including **classes, interfaces, inheritance of responsibilities through composition, ArrayLists, user input, and unit testing with JUnit**.

## Features

* Add resistors to a circuit
* Add DC voltage sources to a circuit
* Store circuit elements using `ArrayList`
* Assign element numbers automatically
* Display the circuit in SPICE format
* Interactive command-line user interface
* End the program using the `end` command
* Run JUnit tests for the `Voltage` class

## How It Works

The user enters circuit elements using the following format:

```text
r <node1> <node2> <resistance>
v <positiveNode> <negativeNode> <voltage>
```

For example:

```text
r 1 2 1000
v 0 1 5
```

The program stores each component and automatically assigns it an element number.

Entering:

```text
spice
```

displays the circuit in SPICE netlist format.

Entering:

```text
end
```

ends the program.

### Example

**User input:**

```text
v 0 1 5
r 1 2 1000
r 2 0 2000
spice
end
```

**SPICE output:**

```text
V1 0 1 DC 5.0
R1 1 2 1000.0
R2 2 0 2000.0

All Done
```

### Main Classes

**`Circuit.java`**

* Controls the main program logic
* Processes user commands
* Stores resistors and voltage sources
* Generates the SPICE representation of the circuit

**`CircuitInterface.java`**

* Defines the methods required for communication between the circuit and user interface

**`CircuitUI.java`**

* Handles command-line input and output
* Receives user commands
* Displays the SPICE representation

**`Resistor.java`**

* Represents a resistor
* Stores the two connected nodes and resistance value
* Generates the resistor's SPICE representation

**`Voltage.java`**

* Represents a DC voltage source
* Stores positive and negative nodes and voltage
* Provides a voltage getter
* Generates the voltage source's SPICE representation

**`UserMain.java`**

* Contains the `main` method
* Creates the circuit and starts the program

**`VoltageTest.java`**

* Contains JUnit tests for the `Voltage` class
* Tests the `getVolt()` and `toString()` methods

## Running the Project

1. Open the `AnalogCircuit` project in **NetBeans**.
2. Build the project.
3. Run `UserMain.java`.
4. Enter circuit components using the required format.
5. Enter `spice` to display the circuit.
6. Enter `end` to exit the program.

### Input Format

**Resistor:**

```text
r node1 node2 resistance
```

Example:

```text
r 1 2 1000
```

**Voltage Source:**

```text
v positiveNode negativeNode voltage
```

Example:

```text
v 0 1 5
```

## Testing

JUnit tests are included for the `Voltage` class.

The tests verify:

* The voltage value returned by `getVolt()`
* The correct SPICE string generated by `toString()`

The project can be tested using the JUnit testing tools available in NetBeans.
